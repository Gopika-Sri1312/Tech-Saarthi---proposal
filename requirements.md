# Tech Saarthi – Requirements

## Purpose
Tech Saarthi is a citizen-focused AI assistant for government services in India.  
It guides citizens step-by-step through applications, provides real-time updates, and notifies about new schemes.

## Functional Requirements
1. AI guidance and eligibility checks
2. Multi-language & voice support
3. Document upload and auto-fill forms
4. Notifications via SMS/email/app
5. Dashboard showing application status
6. Alerts for new schemes
7. Offline / low-bandwidth access

## Non-Functional Requirements
1. Simple, user-friendly interface
2. Fast response time for AI queries
3. Secure storage of citizen data (simulated in prototype)
4. Accessibility for rural/low-literacy users
