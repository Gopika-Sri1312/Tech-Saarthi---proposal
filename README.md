# Tech Saarthi – Citizen-Focused AI Assistant

## 📌 Problem Statement
Citizens often struggle to understand government schemes, procedures, and services due to complex language and lack of guidance.

## 💡 Solution
Tech Saarthi is an AI-powered assistant that helps citizens access public services, understand schemes, and get step-by-step guidance in simple language.

## 🧠 Key Features
- Natural language queries
- Multilingual support
- Scheme eligibility guidance
- Simple explanations for government services
