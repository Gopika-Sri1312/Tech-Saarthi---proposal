# Tech Saarthi

AI-Powered Public Service Orchestration Platform

Tech Saarthi simplifies access to government schemes using AI.

Features:
- AI scheme guidance
- Document extraction
- Real-time tracking
- Automated notifications

Built on AWS serverless architecture.

AWS Services:
- Amazon Bedrock
- Amazon Textract
- AWS Lambda
- DynamoDB
- Amazon S3
- Amazon SNS
